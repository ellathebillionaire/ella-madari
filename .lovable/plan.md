# ארגון מחדש של כל פרויקט - מקומות קבועים לדברים החוזרים

## העיקרון
כל פרויקט מקבל "עמודת זהות" קבועה בצד שמאל, ותמיד באותו סדר. התוכן הוויזואלי (מסכים, גלריות) משתנה לפי מה שיש בפרויקט, אבל העין תמיד יודעת איפה למצוא את הלוגו, הצבעים וההסבר.

```text
 ┌──────────────────────────────────────────────────────┐
 │ [למעבר לאתר ↖]                     שם הפרויקט        │
 │                                      תיאור קצר       │
 ├───────────────┬──────────────────────────────────────┤
 │  עמודת זהות   │   הפתיחה הוויזואלית                  │
 │  (קבועה)      │   מסכים - אם יש                       │
 │  1. הלוגו     │   אם אין מסכים: הנושא הראשון בגלריה   │
 │  2. צבעים     │                                      │
 │  3. שלבים /   │                                      │
 │     ערכים     │                                      │
 ├───────────────┴──────────────────────────────────────┤
 │  שאר הנושאים - ברוחב מלא, כמו היום                    │
 └──────────────────────────────────────────────────────┘
```

## מה משתנה
1. **הלוגו מקבל מקום של כבוד קבוע** - ראש עמודת הזהות, תמיד באותו מקום ובאותו גודל בכל הפרויקטים. לא עוד ליד הטלפון או מתחת למסכים. ב-SFD שני הלוגואים יחד שם (הראשי גדול, הקצר קטן לידו).
2. **פלטת הצבעים** - תמיד ישר מתחת ללוגו.
3. **הסבר הפרויקט והשלבים** (01, 02, 03 בפרויקטי מקצה לקצה, ערכים ו"התהליך" בפרויקטי מיתוג) - תמיד מתחת לצבעים, באותו עיצוב רשימה.
4. **פרויקט בלי מסכים** (טלי טר, סטודיו אלף, Play Pet Pal ועוד) - אותה עמודת זהות, ולצידה עולה הנושא הראשון של הגלריה, כך שלא נשאר חלל ריק.
5. **פרויקט בלי לוגו** (BetterSeeds) - העמודה מתחילה בצבעים; שום דבר לא מומצא.
6. **בנייד** - הסדר: שם ותיאור, לוגו, מסכים, צבעים, שלבים, גלריה. הלוגו מופיע מוקדם כי הוא מרכזי.

## מה לא משתנה
התמונות עצמן, החלוקה לנושאים, כפתור "למעבר לאתר", הגופנים והרווחים בין פרויקטים.

## בדיקה
צילומי מסך של כל הפרויקטים במחשב ובנייד, לוודא שהלוגו תמיד באותו מקום, אין חללים ואין כפילות לוגו.

## פרטים טכניים
- `src/pages/Index.tsx`: פירוק `logoBlock` מתוך שורת המכשירים; פריסת `grid sm:grid-cols-[220px_1fr]` לפתיחה, עם `aside` קבוע (logo → PaletteDots → ProjectStory/BrandingStory) ותוכן ראשי (מכשירים או `galleryGroups[0]`). שאר הקבוצות ממשיכות בגריד 12 העמודות הקיים.
- הלוגו בגובה אחיד (`max-h-20`, `object-contain`) - נשמרת הפרופורציה, בלי חיתוך.
- `RebrandCompare` ו-`WebsiteBeforeAfter` נשארים בתוכן הראשי.
- עדכון כלל ב-AGENTS.md על עמודת הזהות הקבועה, והרצת הבדיקות הקיימות.
